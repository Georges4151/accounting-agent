# 基于RAG的建筑企业会计凭证智能录入系统

> 本科毕业设计项目 | 基于检索增强生成（RAG）技术实现的建筑企业智能会计核算辅助系统

## 项目简介

本系统面向建筑企业财务管理场景，利用大语言模型（LLM）与检索增强生成（RAG）技术，实现会计凭证的智能录入、科目推荐、发票识别、自动折旧、期末结转及财务报表生成等功能。系统通过检索历史凭证分录构建上下文，辅助LLM生成准确的科目建议，有效解决了建筑企业科目体系复杂、手工录入易错的问题。

## 核心功能

### AI智能功能

- **RAG智能科目推荐** — 用户输入摘要与金额后，系统检索历史相似凭证分录作为上下文，调用LLM推荐最匹配的会计科目，支持历史学习与关键词规则双重匹配
- **AI凭证生成** — 用户用自然语言描述业务（如"收到甲方工程款10万元"），系统自动生成完整记账凭证
- **AI摘要推荐** — 选择科目后自动加载该科目历史常用摘要，支持点击选择与实时过滤
- **发票OCR识别** — 上传发票图片，调用视觉模型自动提取发票类型、号码、金额、交易方等信息
- **多Agent智能助手** — 基于LangGraph构建路由Agent，自动识别用户意图并分发到记账、报表、税务、分析、问答等专业Agent

### 账务处理

- **凭证管理** — Excel式分录录入，支持Tab/Enter/方向键导航、Ctrl+V批量粘贴、3秒防抖自动保存草稿
- **实时借贷平衡** — 不平衡时红色背景+脉冲边框提示，平衡时绿色边框确认
- **凭证复核流程** — draft→submitted→reviewed→approved→posted，制单人不能复核自己的凭证
- **出纳独立复核** — 现金/银行科目凭证需出纳单独复核（可开关）
- **期末结转** — 损益类科目自动结转，支持收入、费用、成本分类结转
- **会计期间管理** — 支持期间封账与结转

### 财务管理

- **固定资产** — 自动折旧计算，支持补提折旧、满折处理、状态流转（active→fully_depreciated）
- **报表中心** — 资产负债表、利润表、现金流量表、总账、明细账、日记账
- **预算管理** — 预算编制、执行监控、预算汇总
- **税务管理** — 税务申报、税负分析、税务汇总
- **发票管理** — 发票录入、OCR识别、归档管理
- **银行对账** — 银行对账单导入与自动核对
- **应收应付核销** — 往来核销与账龄分析

### 系统管理

- **多角色权限** — 管理员、会计、出纳、复核人，基于RBAC控制
- **多账套管理** — 账套隔离，成员制访问控制，支持归档
- **USB Key安全认证** — 密钥绑定USB硬件序列号（SHA-256哈希存储），自动检测验证
- **审计日志** — 全操作日志记录
- **数据备份恢复** — 数据库备份与恢复
- **数据导入导出** — 支持Excel格式导入导出凭证与科目
- **多模型配置** — 支持配置不同LLM模型与API Key

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 18+
- [Ollama](https://ollama.com/)（本地大模型推理）
- PostgreSQL（生产）或 SQLite（开发）

### 1. 克隆仓库

```bash
git clone https://github.com/Georges4151/accounting-agent.git
cd accounting-agent
```

### 2. 后端启动

```bash
cd backend

# 创建虚拟环境
python -m venv venv
source venv/bin/activate        # Linux/Mac
# venv\Scripts\activate         # Windows

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入数据库连接、JWT密钥、加密密钥等配置

# 初始化数据库
python seed_accounts.py

# 启动服务
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 3. 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 开发模式启动
npm run dev

# 生产构建
npm run build
```

### 4. 拉取Ollama模型（可选）

```bash
# 推荐模型（中文发票识别效果好）
ollama pull qwen3-vl:4b

# 文本对话模型
ollama pull qwen2.5:7b
```

### 5. Docker一键部署

```bash
docker-compose up -d
```

访问 `http://localhost` 即可使用。

## RAG技术说明

本系统的核心创新点在于将RAG技术应用于会计科目推荐场景：

1. **检索阶段** — 用户输入交易摘要与金额，系统从历史凭证分录中检索相似记录
2. **增强阶段** — 将检索结果作为上下文信息，与用户输入拼接构造Prompt
3. **生成阶段** — 调用大语言模型，基于上下文生成科目推荐结果

相比纯规则匹配，RAG能处理未见过的交易描述；相比纯LLM调用，RAG通过历史凭证约束输出范围，减少幻觉问题，提高推荐准确率。

系统同时维护40+关键词规则作为兜底匹配，确保在LLM不可用时仍能提供基本推荐能力。
